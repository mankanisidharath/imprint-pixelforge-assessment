PixelForge Assessment user guide

This guide explains the image generation screens and how to read their statuses and prices.

Current availability: This assessment branch has a preview interface. The estimate and submission endpoints are not implemented yet, so estimates are unavailable and submitting the form does not create an image.

Creating an image

  1. Choose Generate in the sidebar and enter a prompt describing the image. The counter shows the prompt length; the limit is 4,000 characters.
  2. Select a square, landscape, or portrait size and a low, medium, or high quality.
  3. Optionally add up to four reference image URLs. Use Remove to remove a URL.
  4. When estimates and submission are connected, review the estimated cost range and choose Generate.

Estimates and charges

The estimated range includes a 25% service fee. The actual charge is calculated when an image finishes and depends on the tokens used. Failed generations are free. If an estimate cannot be loaded, the page displays “Estimate unavailable.”

Generation history

Choose History to see your generations, their prompts, size, quality, cost, and creation time. Pending generations update automatically while the page is open.

  • Queued: Waiting to start. A note may explain the wait.
  • Processing: The image is being generated.
  • Succeeded: The image is ready and the final charge is displayed. Select the image to open it at full size.
  • Failed: The generation was not charged. Review the error and select Try again to return to the form.

Image links last 24 hours. After a link expires, the history card displays an expiration message. Use the pagination controls to browse older results.

Account settings

Open the user menu in the sidebar to access your profile and account settings or to sign out.
